# 株式会社アールズ 日常業務自動化環境

株式会社アールズ（名古屋市北区・厨房機器買取 / 不用品回収 / 遺品整理 / 残置物撤去 / ハウスクリーニング）の
日常業務を **Claude Code のサブエージェント6体で半自動化**するプロジェクト。

会社情報・共通ルール（文体・景表法・下書き前提の運用）は `CLAUDE.md` を参照。
チームの顔ぶれは `docs/team-meikan.html`（チーム名鑑）で見られます。

## エージェント（実在担当者名として対外的にも使える）

| 名前 | 呼び出し名 | しごと | 出力先 |
| --- | --- | --- | --- |
| 文野（ふみの） | `fumino` | 残置物LPコラム / WordPress買取コラム・事例 | `output/seo/` |
| 三宅（みやけ） | `miyake` | GBP投稿下書き（3店舗を書き分け） | `output/gbp/` |
| 羽鳥（はとり） | `hatori` | X投稿（2オーディエンス×2案） | `output/x/` |
| 売野（うりの） | `urino` | B2B営業メール（件名3案+本文） | `output/outreach/` |
| 目黒（めぐろ） | `meguro` | 型番→製造年・相場・販路の査定メモ | `output/valuation/` |
| 早川（はやかわ） | `hayakawa` | toC問い合わせへの返信下書き（種別自動判定） | `output/reply/` |

日比野は会社全体の総合窓口・最終責任者という位置づけ。各担当の成果物は最終的に日比野がレビューする。

## 使い方

メインの対話で名前で呼ぶだけです：

```
文野、夜逃げ物件の残置物処分費用の相場でLPコラムを1本お願い
目黒、ホシザキ HRF-120AT の査定メモを作って
早川、この問い合わせに返信を作って（受信メールを貼り付け）
```

名前を呼ばなくても、依頼内容から自動で担当に振り分けられます。

## 運用ルール（要点）

- 成果物は**すべて下書き**。送信・公開は必ず日比野さんのレビュー後に手動で行う
- 金額は「目安」「現地確認のうえ」。誇大表現は禁止（景品表示法）
- 不確かな事実には `【要確認】` が付く。レビュー時に埋めるか削る
- Gmail宛先は `inforsnagoya`（「inforsnagoro」は誤記）
- GBPは3店舗で同一文の使い回し厳禁（過去に重複検出で削除歴あり）
