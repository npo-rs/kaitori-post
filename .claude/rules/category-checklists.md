# カテゴリ別リサーチ観点チェックリスト

kaitori-researcher が商品カテゴリに応じて追加で確認する項目。
共通項目（定価・発売時期・相場レンジ・需要・キーワード）に**上乗せ**して使う。

## 腕時計（ロレックス・オメガ・グランドセイコー 等）
- 型番の世代差（例：116610 と 126610 のムーブメント・ケース径差）
- 付属品：箱・保証書（ギャランティ）・余りコマ → 価格差の目安
- 保証書の日付／並行・国内正規の別
- オーバーホール履歴、風防・ベゼルの状態、社外パーツの有無
- 生産終了・廃番かどうか（廃番は相場が動きやすい）
- 為替・金相場の影響を受けるモデルか

## スマートフォン / タブレット
- 容量・カラー・キャリア（SIMフリー / 各社版）
- ネットワーク利用制限（○/△/×）とその価格影響
- バッテリー最大容量、アクティベーションロック解除の要否
- 画面・背面ガラスの割れ、修理歴（純正/非純正）
- 新型発表・発売のタイミング（発表前後で相場が下がりやすい）
- 初期化・データ消去の案内を必ず入れる

## ブランドバッグ / 財布
- ライン名・型番・サイズ（MM / GM 等）・素材（モノグラム/ダミエ/エピ 等）
- 製造番号（シリアル・デイトコード）と真贋確認の観点
- 状態：角スレ、ハンドルの焼け、金具のメッキ剥がれ、内側のベタつき
- 付属品：保存袋・箱・ショルダーストラップ・レシート
- 廃番／人気カラーかどうか

## 貴金属・ジュエリー
- 素材の刻印（K18・Pt900 等）と重量
- 金・プラチナの当日相場に連動する旨（記事では「日々変動」を明記）
- 宝石の有無・鑑定書/鑑別書の有無
- ブランド品かノーブランドか（ブランド価値が乗るか）

## カメラ / レンズ
- 型番・マウント・世代
- ショット数（シャッター回数）、センサー・レンズのカビ/クモリ/チリ
- 付属品：バッテリー・充電器・元箱・フード・キャップ
- 動作確認項目（AF・絞り・手ブレ補正）
- ミラーレス移行による一眼レフ相場の傾向

## 楽器・オーディオ
- シリアル・製造年・製造国（同型でも産地で相場差）
- 打痕・ネック反り・電装系の動作
- 純正ケース・付属ケーブルの有無

## ホビー / トレカ / フィギュア
- 版・初版・再販の別、限定品かどうか
- 未開封／開封済み、外箱の状態
- トレカはグレーディング（PSA等）の有無とグレード
- 相場の変動が激しい旨を明記（記事では取得時点を書く）

## 家電・PC
- 型番・年式・付属品（リモコン・純正アダプタ）
- 製造年による買取可否ライン（一般に製造から5〜7年程度）
- 動作確認・初期化の要否
- PCはCPU/メモリ/ストレージ構成、OSライセンス、バッテリー劣化

## 化粧品・美容機器
- **効果効能に踏み込まない**（薬機法／`ng-expressions.md` 3・2章を参照）
- 使用期限・製造番号・開封の有無
- 買取不可条件（使用済み・期限切れ）を明記

---

該当カテゴリがない場合は共通項目のみで進め、
「このカテゴリ特有の観点」をリサーチメモの末尾に自分で1〜3個立てて記載する。
