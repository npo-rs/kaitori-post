# 表現ルール / NG表現集（全エージェント共通の基準）

買取記事・SNS投稿で使ってよい表現・使ってはいけない表現の唯一の基準。
researcher / blog-writer / sns-writer / editor はすべてこのファイルを参照する。

## 1. 景品表示法（優良誤認・有利誤認）

根拠なく「他社より優れている／必ずそうなる」と読める表現は使わない。

| NG | 言い換え例 |
| --- | --- |
| 業界最高値・日本一・No.1 | 高価買取に力を入れています / 相場を踏まえた査定 |
| 必ず高く売れる・確実に○円 | ○円前後が目安（状態・時期により変動） |
| どこよりも高く・他店より高価 | 他社見積もりがあればご提示ください |
| 100%・完全・絶対 | （原則使わない。使うなら対象を限定する） |
| 最安・最短・唯一 | （客観的な根拠を併記できない限り使わない） |

- No.1 等を書く場合は「いつ・誰の・何の調査か」を併記できるときだけ。書けないなら削除。
- 「無料」は条件（送料・キャンセル料の負担者）を明示する。

## 2. 薬機法（化粧品・美容/健康関連）

化粧品・美容機器・健康器具・サプリ等を扱う記事で、効果効能を断定しない。

| NG | 言い換え例 |
| --- | --- |
| シミが消える・痩せる・治る | メーカーが訴求しているシリーズ / 人気のライン |
| アンチエイジング効果がある | エイジングケア（年齢に応じたお手入れ）として人気 |
| 医薬品的な表現（改善・予防） | （買取記事では効果に触れず、需要・相場の話に寄せる） |

- 買取記事では**そもそも効果効能に踏み込まない**のが安全。需要・人気・相場で書く。

## 3. 価格表現

- 価格・買取金額には必ず「目安」「状態・時期により変動」が分かる記述を添える。
- 断定形の単一価格（「買取価格は○円です」）は使わない → 「○〜○円が目安」。
- リサーチメモにない価格は書かない。必要なら `<!-- 要確認: ... -->` を残す。
- 相場の取得時点（例：2026年8月時点）を明記できるなら明記する。

## 4. 事実の扱い

- リサーチメモにない事実（スペック・発売日・付属品・相場）を創作しない。
- 推測を書くときは「推測」「〜と思われます」と明示する。
- 真贋・鑑定に関する断定（「本物です」「偽物です」）は書かない → 「真贋確認を行います」。

## 5. その他の注意

- 個人情報・買取実績の顧客特定情報は書かない。
- ブランドの公式表記（スペル・カタカナ表記）を揃える。例：ルイ・ヴィトン / ロレックス。
- 比較記事で他社名を出す場合は事実のみ。評価・断定はしない。
- 煽り表現（今すぐ・今だけ・急いで）は乱用しない。使うなら根拠（キャンペーン期間等）とセット。

## 6. チェック時の判定基準（editor用）

- NG表現が1つでも残っている → **要修正**
- 価格に「目安・変動」の注記がない → **要修正**
- `<!-- 要確認 -->` が残っている → **要修正**（担当者判断が必要な旨をレポートに明記）
- 上記なし＋事実整合OK → **OK**
